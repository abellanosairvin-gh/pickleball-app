# Non-tournament games are genderless; the Gender Balance Rule applies to Tournament sessions only

The Gender Balance Rule (both teams share the same gender make-up) was a hard constraint on every generated and hand-picked game (ADR-0002). On a regular night it mostly got in the way: with an uneven roster it starved the minority gender of legal partners, blocked otherwise-fine manual picks, and thinned the Suggest list. Gender only matters where the bracket seeds top-N per gender and draws MF finals - Tournament sessions. So the scheduler takes a `genderRule` switch that is on only when the session's Tournament option is ticked; Generate, Top up, and the Fixed-game Suggest button follow it. Non-tournament sessions (random, rating, manual, ladder) accept any four players in any split, and hand-picked games are the organizer's override - the picker never blocks a gender split, in any session. Players still carry a gender - the roster count, the M/F leaderboards, and tournament seeding use it.
