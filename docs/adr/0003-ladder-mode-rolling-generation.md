# Ladder mode generates rolling matchups from results, unlike every other mode

ADR-0002 pre-generates the whole schedule up front, but Ladder mode (winners vs winners, losers vs losers) cannot: the next matchup depends on results as they land. In Ladder sessions, "Generate" only seeds one game per idle player (random, rule-respecting, nothing queued is deleted), and each completed score feeds a matchmaker that queues a new game whenever four free players share a pool — winners with winners; losers and not-yet-played late arrivals together. Winners are reshuffled into new pairings (fewest repeated partnerships preferred) rather than kept as fixed teams, results trump the rating-compatibility and gender-balance rules (hence "genderless" in its UI label), and the Game Cap remains a hard limit.
